# Eight Queens Visualizer (Задача о 8 ферзях) 👑

Полноценное интерактивное десктопное приложение для решения и визуализации алгоритма «Задачи о 8 ферзях» на **Electron + React + TypeScript + Tailwind CSS + Framer Motion**.

---

## 🚀 Стек технологий

- **Десктопная платформа:** Electron 34
- **Фронтенд:** React 19, TypeScript
- **Стилизация:** Tailwind CSS (современная тёмная тема)
- **Анимации:** Framer Motion (плавный scale появление/исчезновение ферзей, пульсация лучей атак, цветовые переходы клеток)
- **Иконки:** Lucide React (SVG-иконка ферзя `Crown`, системные индикаторы)
- **Эффекты победы:** Canvas Confetti

---

## 🎮 Возможности и режимы

### 1. Интерактивный (Ручной) режим
- Пользователь кликает по клеткам доски 8x8 для установки ферзя.
- Повторный клик по установленному ферзю снимает его с доски.
- **Защита от некорректных ходов:** Если пользователь пытается поставить фигуру на битое поле, фигура не ставится, а все атакующие ферзи и их лучи атаки (по вертикалям, горизонталям и диагоналям) на 650мс подсвечиваются ярким неоновым красным цветом.
- **Анимация победы:** При успешной расстановке всех 8 ферзей без взаимных угроз запускается салют конфетти и открывается модальное окно победы с возможностью осмотреть доску.

### 2. Режим алгоритма (Backtracking / Поиск с возвратом)
- Пошаговая визуализация работы рекурсивного алгоритма с возвратом на генераторах (Generator Function `function*`):
  1. **Попытка (Try):** Полупрозрачная иконка ферзя появляется на целевой клетке.
  2. **Проверка (Check):** Подсветка клетки и проверка пересечений по вертикалям и диагоналям.
  3. **Фиксация (Safe):** Если позиция безопасна, ферзь становится непрозрачным (золотой цвет с изумрудным подтверждением), и алгоритм переходит на следующую строку.
  4. **Конфликт и Откат (Backtrack):** Если найдена угроза или в текущей строке нет свободных клеток, фигура убирается, алгоритм откатывается на предыдущую строку и смещает фигуру вправо.
- **Интерактивные элементы управления:**
  - Кнопка **«Визуализировать Backtracking» (Запуск / Пауза)**.
  - Кнопка **«Шаг вперед»** для покадрового анализа каждого шага алгоритма.
  - **Ползунок скорости** от 50мс до 800мс на шаг.
  - **Счётчик найденных решений** (от 0 до 92).
  - Опция **«Пауза при нахождении решения»** или непрерывный поиск всех 92 решений.
  - **Галерея найденных решений:** выпадающий список и кнопки переключения для быстрого перехода к любому найденному решению.
- **Информативный статус-бар:**
  - Отображает текущее действие с шахматной нотацией (`a1`-`h8`), конфликтующие фигуры, глубину отката и счетчик ходов.

## 📂 Архитектура проекта

```
src/
├── components/
│   ├── Board.tsx          # Шахматная доска 8x8 с внешней подсветкой
│   ├── Square.tsx         # Клетка доски с Framer Motion анимациями и лучами атак
│   ├── Controls.tsx       # Боковая панель управления (кнопки, ползунок скорости, галерея)
│   ├── StatusPanel.tsx    # Статус-бар под доской с индикаторами и легендой
│   ├── Header.tsx         # Верхняя панель приложения
│   ├── VictoryModal.tsx   # Модальное окно победы с конфетти
│   └── HelpModal.tsx      # Справка по правилам и алгоритму
├── hooks/
│   └── useEightQueens.ts  # Кастомный хук управления состоянием доски и генератором бэктрекинга
├── utils/
│   ├── chess.ts           # Шахматная геометрия, валидация и лучи атак
│   └── solver.ts          # Generator-based Backtracking solver (все 92 решения)
├── types/
│   └── index.ts           # TypeScript типы и интерфейсы
├── App.tsx
└── main.tsx

electron/
├── main.ts                # Главный процесс Electron (окно, жизненный цикл)
└── preload.ts             # Безопасный Context Isolation мост
```

## 🛠 Запуск и сборка

### Установка зависимостей:
```bash
npm install
```

### Запуск в режиме разработки (Electron Desktop):
```bash
npm run electron:dev
```
Команда запускает Vite Dev Server на порту `5173` и стартует окно Electron с поддержкой Hot Module Replacement (HMR).

### Запуск веб-версии в браузере:
```bash
npm run dev
```

### Сборка и предварительный просмотр Desktop-приложения:
```bash
npm run electron:preview
```

### Сборка дистрибутива (.exe для Windows):
```bash
npm run electron:build
```
Готовый установщик сохранится в папке `release/`.
